# שדות קלט לפי מסך — „הצעד הבא”

המסמך מרכז לכל מסך את הערכים שקולטים מהמשתמש, ואיך שולחים אותם לשרת.

**הסבר לעמודות:**
- **שם בשרת:** השם המדויק שבו שולחים את השדה. זה גם השם שיופיע ב־`error.details[].field` כשהשרת מחזיר שגיאת ולידציה. כדאי לתת לשדות בטופס (ב־React Hook Form וב־Yup) את אותם שמות בדיוק.
- **סוג שדה מוצע:** סוג ה־`input` המתאים (`text`, `email`, `select` וכו').
- **חובה:** ✅ = חובה. ריק = רשות.
- **כללים:** אותם כללים שהשרת בודק. כדאי לבדוק אותם גם בטופס, כדי שהמשתמש יראה שגיאה לפני השליחה.

> **שדה רשות שנשאר ריק:** מחרוזת ריקה (`""`) נשמרת בשרת כ־`null`. בעריכה (PATCH), שליחת `null` מוחקת ערך קיים.

## 1. הרשמה
**נשלח אל:** `POST /api/auth/register`

| תווית בטופס | שם בשרת | סוג שדה מוצע | חובה | כללים |
|---|---|---|---|---|
| שם מלא | `fullName` | `text` | ✅ | 2–100 תווים |
| דוא״ל | `email` | `email` | ✅ | כתובת דוא״ל תקינה, עד 255 תווים |
| סיסמה | `password` | `password` | ✅ | 8–72 תווים, לפחות אות אחת וספרה אחת |
| אימות סיסמה | `confirmPassword` | `password` | ✅ | זהה לסיסמה. **נבדק רק בצד הלקוח, ולא נשלח לשרת** |
| מוסד | `institutionId` | `select` | ✅ | מספר (`id`). האפשרויות מגיעות מ־`GET /api/institutions/public`. בתווית אפשר להציג שם ועיר, למשל "מכללת אופק — ירושלים" |
| תחומים שאני מחפש | `jobRoleIds` | בחירה מרובה: תיבות סימון (`checkbox`) או `select multiple` | | מערך מספרים, עד 20. האפשרויות מגיעות מ־`GET /api/institutions/{institutionId}/job-roles`, לפי המוסד שנבחר |

**הערות:**
- את `institutionId` שולחים כמספר, לא כמחרוזת.
- את `jobRoleIds` שולחים כמערך של מספרים, למשל `[1, 3]`. אם לא נבחר כלום, שולחים `[]`.
- כשהמשתמש מחליף מוסד, טוענים מחדש את רשימת התחומים ומנקים את מה שכבר נבחר.
- ב־Yup: `yup.array().of(yup.number().required()).max(20, 'אפשר לבחור עד 20 תחומים')`.

## סיכום: שדות שצריך להמיר לפני שליחה

| שדה | הערך שמגיע מהטופס | מה השרת מצפה לקבל |
|---|---|---|
| `institutionId`, `statusId`, `jobRoleId`, `userId` | מחרוזת, למשל `"3"` | מספר, למשל `3` |
| `jobRoleIds` | מערך מחרוזות, למשל `["1", "3"]` | מערך מספרים, למשל `[1, 3]` |
| `suggestedDays`, `sortOrder` | מחרוזת | מספר |
| `interviewAt` | `"2026-10-21T10:00"` (בלי אזור זמן) | ISO מלא עם אזור זמן |
| `isActive`, `isFinal` | `true` / `false` | `true` / `false` (בוליאני, לא מחרוזת) |
| שדה רשות ריק | `""` | `""` או `null`, ושניהם נשמרים כ־`null` |
| `submittedOn`, `dueOn` | `"2026-10-21"` | כמו שהוא |
